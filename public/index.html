      How to play

      1. You get an answer on an exit sign, like Paris.
      2. Write a question that has that answer, in 60 seconds. Don't put the answer in the question.
      3. Rarer questions earn more gas. Almost everyone asks "What is the capital of France?" (10 points). Hardly anyone asks "Which city has a lattice iron tower built for the 1889 World's Fair?" (100 points).
      4. Be specific. "What is a city?" is too vague, since lots of answers fit, so it scores 0. So does a question the answer doesn't fit.

      Seven cards a day, with a new set at midnight UTC. A full tank is 700 points.
